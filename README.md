# MovieWatch

MovieWatch is a simple personal watchlist for movies I want to watch and
movies I have already seen.

This project is created for the Web Technologies Basics (SE_19) and
Software Development Basics (SE_01) learning units.

## Pages

- `index.html`: home page with a short intro
- `watchlist.html`: all movies in a overview
- `about.html`: about the project and imprint


## How to run

Open `index.html` in a browser.
